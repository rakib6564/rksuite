A library of custom Elementor widgets for the RK suite.

== Description ==
RK Elements adds an "RK Elements" category to the Elementor panel with:

Layout (Tier 1)
* RK Listing Grid — query any post type / RK Core CPT into a responsive grid.
* RK Post Carousel — horizontal, snap-scrolling post carousel.
* RK Filterable Grid — grid with taxonomy filter buttons.

Content (Tier 2)
* RK Heading, RK Counter, RK Progress Bar, RK Testimonial, RK Pricing Table,
  RK Team Member, RK Accordion.

Requires Elementor. Registers with RK Hub when present (Pro tier) and reads
RK Core post types automatically. If Elementor is inactive the widgets stay
dormant and an admin notice explains why — the plugin never fatals.
