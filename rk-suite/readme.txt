The complete RK toolkit in one plugin. Enable only the modules you need.

== Description ==
RK Suite bundles the RK modules and lets you switch each one on or off from a
single Modules screen. Disabled modules never load, so you only pay for what you
use.

Bundled modules:
* RK Core (free) — CPT, taxonomy and custom-field engine. Enabled by default.
* RK Migrate (free) — Elementor site export/import, rollback, Site Doctor.
* RK Elements (pro) — Elementor widget library (needs RK Core).

One license key sets the tier (free / pro / agency) that unlocks Pro/Agency
modules. Each module boots in isolation — a runtime error in one cannot take the
others down. Enabling a module also enables its required modules automatically.
